# 可复用内容、会话与来源关联

2026-09-09 权限更新：局域网共享现与本机拥有相同的应用权限，开放会话、会话关联及中间图片、编辑、回收站、整理配置和语义检索。仍无需登录，保留局域网地址及同源校验。下文原有 LAN 只读或私有内容隔离描述为历史设计，以本更新和 README 的局域网共享说明为准。

更新：2026-09-08。此文以用户试用后的澄清为准，替代首版把操作记录作为元素的设计。

## 已确认的边界

- 元素有文字、图片、会话三种。会话沿用普通元素的身份、标签与关联能力；不进入“全部内容”，入口在 Agent 会话列表。关联选择器仍可选择会话。
- 消息、工具调用、执行记录、编辑动作都不是元素。必要的消息定位、实际输入和参数留在聊天历史及保存绑定的元数据中。
- 图片按普通关联连接会话、参考资料、提示词和其他图片。关联可编辑、解除；修改关联不改写底层历史。
- 会话详情直接展示对话摘录：从关联内容进入时，以对应消息为中心，显示附近的对话，并提供“打开会话”按钮。行号、轮次和内部任务编号不展示。
- 提示词正文表达最终画面本身。人物、服装、姿势、构图、场景、光线等实际采用的参考特征必须具体展开。正文不依赖“图 1”“原图”“保持原来的”等指代，也不混入来源说明。参考关系通过元素关联表达。

## 保存行为

保存图片先提交图片与会话、已知资料、编辑原图之间的关联，再排队提炼恰好一份独立提示词。提炼时实际读取目标图片及参考图，结合历史资料正文、已采纳修改和已记录工具提示词。结果直接保存为普通文字，与图片及采用的来源元素关联。

图片保存与模型提炼分开提交，网络调用和图像处理不占用数据库事务。提炼失败不回滚已保存的图片，界面提供重试；重试复用原图片，成功后重复保存不再重复生成提示词。已删除的图片或提示词不会因为重试保存而自动复活。

提炼遇到来源版本变化时允许在同一轮重新读取；已提出建议仍校验各自保存的来源快照，旧建议不能因重新读取而跳过校验。已提供的图片再次读取只返回最新资料信息，不重复附图或消耗图片额度。工具摘录必须包含所属历史轮次 `turnId`，缺失字段会返回具体修正要求。

来源冲突和可修正的提交参数错误若未在当前轮解决，自动换新上下文重试，最多额外两次，并将上次错误作为修正依据。只在当前任务仍未完成时重新排队，已保存结果不会被重复创建；用户停止、应用关闭、资料删除等情况不自动重试。达到上限后展示具体原因及手动重试入口。重试预算属于这次恢复过程，用户手动重试时重新计算。

自动提炼使用独立执行上下文，后台执行记录不加入用户对话列表，不改变原会话续聊所用的线程。与普通聊天共用执行槽位，排队任务在空闲时继续。重启会把中断任务标为可重试，不无限自动重试。

人工触发的“提取元素建议”保留候选采纳方式，最多 3 份完整成果。它与保存图片附带的一份提示词不同。零碎修饰、确认语句和操作步骤不逐句入库。

## 数据和界面契约

- `chat_turns` 保存原始消息、读取的资料快照、图像产物及实际可观察参数。原始工具输入与整理出的可复用提示词有各自身份，不能把重写稿冒充实际调用原文。
- `chat_element_bindings` 保存产物与元素的稳定绑定，并以 `data` 保存必要的版本、来源和提取依据。绑定是元数据，不可作为内容节点浏览。
- `chat_session_elements` 保证一个会话对应一个元素。永久删除后的空绑定不会自动重新创建。
- `chat_prompt_jobs` 保存图片提炼任务的状态、执行尝试及提示词绑定；自动执行对应的聊天记录标为内部记录。
- 内容列表默认 `scope=library`，排除会话；`kind=session` 或关联选择器的 `scope=active` 可以读取会话。标签、关系、画布、详情和关联选择器复用现有元素能力。
- `GET /api/elements/:id/conversation?from=:elementId` 返回与该内容对应的会话摘录。没有保存锚点的人工关联显示最近对话。完整消息通过 Agent 入口读取。
- 会话及自动保存的中间图片维持本机范围。普通保存的图片、提示词沿用普通内容共享范围；LAN 读取过滤私有元素及其关联，不公开聊天记录和绑定元数据。

自动提示词整理最多携带最近 20 条用户对话、较早 12 条含资料的对话中的来源、12 份资料和 8 张图片（包括结果图）。消息材料限制约 28,000 字符，资料正文按份限制。保留已有工具输入，但不承诺还原执行器未提供的隐藏参数。常见上下文指代会在提交时拒绝，完整性还由模型结合实际图像判断。

## 兼容与删除

schema 16 在已有 schema 14/15 上迁移：旧操作元素的必要信息移入保存绑定，原有来源和结果改为直接关联，用户附加的操作标签与人工关联转到所属会话，然后移除操作元素。新的数据库写入拒绝操作类型。图片、文字、会话内容及其身份保留，迁移失败整体回滚。

永久删除清理该元素的受管理文件与历史副本，保留其他独立保存的元素。会话删除清理原始对话及引用依据，独立保存的提示词和图片仍保留；来源删除使待采纳的失效建议不可采纳。文件清理在提交后执行，失败持久记录并可重试。外部执行器自行保存的历史、旧版未登记工作文件和人工导出文件不在自动清理范围内。

## 验证

针对修订的测试覆盖：没有操作节点、会话默认列表隐藏及普通关联编辑、指定位置的前后摘录、继承前文文字和实际参考图的自动提炼、拒绝依赖上下文的正文、失败重试、去重、永久删除、LAN 私有范围，以及迁移失败回滚和用户附加信息保留。

最终全量测试 297 项通过；随后针对提示词边界的 12 项复测通过。前端构建与架构检查通过。页面验证覆盖会话摘录、普通关联操作、自动保存提示词及跨长会话跳转。

另核对了用户这次实际记录的副本：图片和文字原值、会话原文均保留，SQLite 完整性和外键正常。该实际记录中已生成的独立提示词具体描述人物、服装、姿势、卧室与暖光，没有旧图编号或依赖旧图的操作指令；这是一份样例验证，不代表所有提示词的语义质量均已覆盖。
