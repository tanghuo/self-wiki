## 实施决策（sr-design-gate：Inline）

- 草稿由同一资料库持久化；保留当前浏览器旧稿迁移与未确认备份。服务端保存版本，首次发送回执丢失后复用请求标识；空稿也推进版本，避免迟到保存复活旧输入。新增数据库迁移只在隔离测试库演练。
- 数量校验由业务数据层在开始消息的写事务前半段执行，幂等重放优先；前端提前反馈，不能单靠前端校验。
- 回收站新增本机专用缩略图读取能力；保持普通详情、原图与 LAN 的现有可见性限制。
- 原始标签与显示名分离；解除别名不删除绑定、不静默截断超限标签。
- 跨工作区状态使用项目已安装 React 19.2 的 Activity，隐藏时暂停 effects 并保留状态。仅已访问工作区保留；对 effect 重启、模态框、列表滚动与画布选择进行回归。React 最低声明同步至 19.2。[官方行为说明](https://react.dev/reference/react/Activity)。
- 新增内容及设置修改使用明确的放弃确认；这只是产品内草稿保护，不是本轮实施授权的额外审批。
