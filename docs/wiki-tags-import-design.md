# 元素标签与图片重复导入

状态：2026-09-07 已实现并验证。用户确认相同图片复用已有元素，并补充本次标签。承接已执行的个人 Wiki 第一版。

## 行为

- 图片和文字共有 `tags: string[]` 属性，与元素关联独立。新建、编辑、详情、卡片展示标签，列表支持单个标签精确筛选。
- 选择或拖入图片后先显示导入对话框，填写本批标签，再明确开始。每个文件展示结果，可以打开保存或复用的元素。
- 标签去掉首尾空白、统一 Unicode NFC，忽略大小写去重；保留首次输入的显示名称。每个元素最多 30 个标签，每个标签最多 60 字。编辑覆盖标签，重复导入合并标签；省略 tags 字段保留原值，空数组清空。
- 重复按原始文件 SHA-256 判断，不做视觉相似识别。完全相同的文件复用最早的在用元素，保留标题、关联和原图，标签取并集；合并超过上限整次失败。同名不同内容创建新元素，明确提示另存。
- 仅在回收站找到重复图片时提示先恢复，不自动恢复或新建。旧版本已经导入的重复元素保留，不自动归并。

## 数据与接口

- Wiki v2 新增 tags、element_tags（内部整数外键），element_images 增加可空 content_hash 和索引。旧表及关联不改写。
- 启动监听前为缺少哈希的旧图片逐个读取并补齐；文件读取在数据库事务外，缺失原图跳过，其他读取错误报告启动失败。补齐可重入，无需全量事务。
- `/api/elements` 创建和 PATCH 支持 tags，所有元素读取返回 tags；列表 `tag` 参数精确筛选；`GET /api/tags` 返回使用中的标签供选择。
- `/api/images` 保留原二进制 body 与 x-file-name，`x-image-tags` 使用 UTF-8 JSON 数组的 base64 编码（避免中文长标签超过 URL/请求头长度）。返回元素字段及 `importStatus: created | reused | same-name`；新建 201，复用 200。
- 图片解码和文件保存在事务外；查重、插入/补标签在短事务中，确保并发导入不产生重复。复用/数据库失败删除本次临时原图；已存在但原图丢失的图片可用本次相同原图修复其文件引用。

## 新增与删除交互修订（2026-09-07）

- 用户要求图片、文字保持同级入口。列表右上角合为“新增内容”，同一弹窗内切换图片/文字并填写标签；草稿和已选文件在切换时保留。拖入图片复用此弹窗，提交仅保存当前类型。
- 原来删除只在详情提供。现为图片和文字卡片都补充直接“删除”，调用原有回收接口；仅成功后移除卡片，失败显示原因。提供固定在窗口底部的撤销操作；回收站仍能恢复文件、标签与关联。只读共享不展示新增和删除控件。
- 验证：147 项测试及架构检查通过，构建与隐藏 Electron 桌面 smoke 通过；测试覆盖统一入口打开实际文件选择器、类型切换、导入标签、删除失败重试、撤销及恢复。截图 `data/wiki-add-content.png`、`data/wiki-delete-cards.png`、`data/wiki-tags-import-mobile.png` 已检查。
- 整体验证期间修正了同时进行的画布改动中数据库依赖放错位置的问题：画布仓库在元素仓库中组装，不进入元素响应对象；相应迁移测试已适配当前版本。
