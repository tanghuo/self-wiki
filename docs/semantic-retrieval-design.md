# 内置语义检索第一版

2026-09-09 权限更新：局域网共享现与本机拥有相同的应用权限，开放会话、会话关联及中间图片、编辑、回收站、整理配置和语义检索。仍无需登录，保留局域网地址及同源校验。下文原有 LAN 只读或私有内容隔离描述为历史设计，以本更新和 README 的局域网共享说明为准。

## 目标和当前事实

`organizationRepository.context` 原来仅按标签、LIKE 关键词及最近 20 项选取最多 40 项；多轮上下文先保留旧候选，可能挤掉新搜索结果。图片没有可检索的描述。后端使用 Node 24 的 `node:sqlite`，Windows 安装包携带独立 Node 运行时。

## 实施决策

- 内置固定版本 sqlite-vec 0.1.9。向量以 SQLite BLOB 保存，第一版用扩展的余弦距离函数精确检索；普通表保持外键级联删除和版本过滤，暂不引入 ANN 或额外数据库服务。已在当前 Windows / Node 24.16 验证扩展加载和余弦计算。
- 在 organization.json 增加独立 `embedding` 配置，旧配置缺少该项时补默认值。默认关闭，预填本机 Ollama 的 OpenAI 兼容接口及 qwen3-embedding:0.6b；模型运行服务需要用户已有或自行安装，不随应用下载模型。支持 HTTP 兼容 embedding 接口、模型、模型版本、维数、超时、topK、密钥环境变量名。
- 所有文本分段覆盖全文；图片通过现有执行器生成纯描述并缓存，描述是派生信息，不能充当正文引用或事实关系的依据。图片描述和向量分别保存，重建向量可复用描述。
- 索引服务后台顺序处理，通过异步 HTTP 调用 embedding，并复用执行器处理图片。模型调用始终位于事务外；领取、成功、失败各用一个短写入。持久化任务版本与令牌保护内容修改、回收站、配置切换、重建和重启；每项最多执行三次，手工重试失败项。正常关闭取消不消耗失败额度，异常中断在重启后保留累计次数。
- 启用后补建已有内容。配置中的 endpoint / model / modelRevision / dimensions 与分段格式共同形成向量空间标识；空间变化自动排队重建，旧空间不参与检索。关闭后终止请求，普通导入和关键词整理继续可用。
- 检索先过滤当前有效内容和版本，再对各分段算距离，按元素聚合；与关键词、标签、最近项目混合选取。保留旧候选的额度有限，确保后续检索可引入新候选。源元素尚无向量时可临时向量化文本；图片初轮分析的描述可用于补检索。
- 设置页显示模型、索引进度、失败诊断、补建/重建/重试入口及语义查询预览。新增 API 仍仅由本地监听提供，LAN 只读分享不开放。

## 验收

验证真实 sqlite-vec 扩展、分段全文覆盖、中文不同措辞候选召回（确定性测试向量，仅检验管道）、模型切换/过期写入/软删除/永久删除/重启恢复/失败重试/取消、HTTP 接口与界面配置、旧配置兼容。构建及现有架构/回归检查通过。真实模型质量与用户机器上的 embedding 服务另行标明验证边界。

## 模型升级边界复核（2026-09-08）

本次按 sr-design-gate 的 Inline 路线核对既有契约，不新增数据库迁移或改变运行配置。`semanticRepository.semanticSpace` 已包含 provider、baseUrl、model、modelRevision、dimensions 和分段格式版本；`configure` 使旧任务失效，检索按空间与内容版本过滤，`complete` 在短事务内检查当前任务后替换单元素向量。

- 输出维数相同不代表模型兼容。换模型、改维数或升级 `modelRevision` 都重新索引；切回原配置仍须重建，旧任务不能因空间标识恢复而重新获得写权限。
- `modelRevision` 是用户维护的版本，不是从 Ollama 或其他服务自动读取的权重指纹。同名权重更新前应关闭语义检索，更新后递增版本并重新启用。应用目前不能保证检测到服务端未声明的模型变化。
- 分段/文本清洗、文档或查询前缀、输出归一化等生成规则变化，也须更新空间标识；后续加入模型适配时需要把相关格式版本一起纳入。
- 当前只有一套活动索引。切换后已完成的新内容逐步可检索，关键词等候选来源保持可用；新旧索引并存、就绪后原子切换和快速回滚需要后续独立实现。
- 增加真实 SQLite 扩展回归场景：同维数换模型、同名版本升级、维数变化、切回旧配置、旧任务迟到成功/失败以及原文/标签保留。
- 验证：`node --test test/semantic.test.js` 共 11 项通过（含 3 个升级/回切子场景），无失败或跳过。本次仅补测试与说明，未改变运行时模型配置。此前本机 `qwen3-embedding:0.6b` 的真实兼容接口请求已成功返回 1024 维向量；这不代表已完成检索质量评测。

## 设计复核

按 sr-review 对以上冻结范围进行本轮自审：普通表避免扩展缺失时迁移失败；密钥只引用环境变量，不在界面返回；新查询必须优先获得候选额度；存储维数与空间版本须校验。修正这些边界后可实施，无用户决策阻塞。
