# 8435015 评审后续修复

本轮按权限、数据丢失与执行可靠性优先处理已核实问题。

| 报告项 | 当前处理 |
| --- | --- |
| H1、M3 | 分享使用独立随机令牌，每次访问检查有效期和取消状态；局域网禁止列出全部分享，也禁止使用旧的管理下载接口。分享不兑换全局配对 Cookie。 |
| M1 | 本机主动生成短码，10 分钟有效、一次使用，重启或关闭共享后失效。每个来源地址每分钟最多尝试 10 次，全局最多 100 次；生成新码重置短码尝试窗口。长令牌二维码继续可用。 |
| M2 | 桌面关闭遇到未保存拦截时显示原生确认，默认取消；取消不停止后端，确认丢弃后才关闭。 |
| M4、M5 | Grok 取消使用进程树终止；POSIX 使用独立进程组，SIGTERM 后升级 SIGKILL，输出管道有关闭兜底。Windows 等待 taskkill 结束后释放生图名额。保留原并发上限，排队显示状态并支持取消。 |
| M6 | 调度兜底扫描降为每秒一次，任务完成和循环展开主动唤醒；详情与批次尝试记录改批量读取。界面轮询降为两秒，页面隐藏时暂停网络轮询。仍保留运行状态汇总所需的实例读取。 |
| L2、L9 | 单文件和目录内容限制为小于 4 GB；单文件复制过程中也检查上限。ZIP 拒绝反斜杠、父目录、绝对路径与冒号路径。 |
| L3、L5、L6 | Grok 模型名必须以字母或数字开头；本地附件识别真实 MIME；保存工作流图片时按 MIME 选择文件名扩展名，保留原有去重。 |
| L10、L11、L12 | 取消分组仅影响选中节点所在的组；单独运行 UI 测试会先构建；分享界面注明文件上限及退出即失效。 |

## 升级与兼容

- 已有长令牌和已配对浏览器继续有效。旧配置里的短码不会自动开启配对窗口。
- 曾发送旧版临时分享链接的用户，仍需在设置中点击“更换配对码”，撤销旧链接及已配对浏览器的全局权限。
- 已配对设备访问临时分享改为使用发送者提供的独立链接；即使取消资料库的配对要求，也不能枚举或直接下载全部临时分享。
- 本轮不自动删除运行历史和工作流产物，不迁移添加来源枚举。外部工具门禁的真实 CLI 行为与 POSIX 分支仍需要对应环境验证。

## 验证边界

新增回归覆盖短码手动开启、单次使用、到期、重置、按来源限速、分享范围隔离、取消关闭、进程树终止、排队取消、ZIP 路径、JPEG/WebP MIME 与文件名、去重和分组保留。构建、单元测试及架构检查通过。

本机原生 Electron 关闭测试在进程启动阶段被 Windows 目录 ACL 拦截，未进入测试逻辑；关闭确认的控制逻辑已通过单元测试。进程树测试在 Windows 上运行通过，POSIX 升级信号分支尚未在 Linux/macOS 实机执行。
