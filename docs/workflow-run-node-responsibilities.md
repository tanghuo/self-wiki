# 运行页的节点职责

执行依据：`src/server/application/workflow/nodes.js`；类型、输入端口和依赖依据：`src/shared/domain/workflow/contracts.js`。运行页的修改仅提交到派生运行，不保存流程默认值。

| 节点 | 执行职责 | 运行页编辑范围 |
| --- | --- | --- |
| 内容 element / 旧 input | 提供文字、图片或其他类型的内容 | 本次输入、固定素材；图片显示本次快照并支持替换、排序、移除 |
| 组合文字 element.parts / 旧 template | 组合本节点的文字与上游引用 | 编辑本节点文字；引用部分展示实际来源内容，保留依赖，不提供连线编辑器 |
| 上游内容 element.upstream | 传递上游值 | 查看实际来源内容和定位来源，不把它伪装成本节点生成的文字或图片 |
| AI 写文字 model | 按输入调用执行器，输出文字或结构化结果 | 仅执行器声明的任务参数；无可编辑参数时不提供编辑按钮。上游提示词与图片由来源节点负责 |
| AI 生成图片 image.generate | 按输入调用生图执行器 | ComfyUI 仅生图参数；其他执行器仅声明的参数，不在此编辑提示词、参考图或连线 |
| foreach | 限制并调度列表的逐项执行 | 批处理上限，不把循环节点作为所有子节点的编辑表单 |
| transform | 按已定义的规则整理输入 | 查看结果；更改处理规则在流程编辑页进行 |
| preview | 展示上游结果 | 查看，不提供内容编辑 |
| review | 暂停，等待选择或文字修订 | 待确认时修改、通过或跳过；通过后下游才继续 |
| library.save | 将上游内容写入资料库 | 展示保存结果；不承担内容编辑或审核 |

统一提交栏固定在视口底部，修改多个节点后统一重新运行。提交前可展开重跑范围；未受影响的成功步骤复用结果，受影响的审核重新等待确认。流程连线、执行器类型、输出格式和处理规则由流程编辑页管理。

验证：覆盖 ComfyUI 编辑区无提示词/参考图编辑器、固定图片快照可见、文字组合显示实际上游内容且保留引用、无参数 AI 不显示编辑、审核/保存无通用编辑，以及长页面滚动时重新运行按钮仍在视口内。
