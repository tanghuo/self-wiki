# 工作流

工作流位于本机侧栏。可以从空白画布组合节点，或复制「批量反推并生图」。执行由后端负责，关闭页面后仍可继续；重新打开后从运行历史查询结果。

## 搭建与运行

1. 新建空白或复制内置示例，给流程命名。
2. 从节点库拖入节点，或点击添加。点击节点编辑配置。「使用上游结果」只切换接收方式，不选择来源、不自动连线。来源由用户从节点端口手动连线确定，不能连接不兼容的类型。
3. 节点库统一使用「元素」入口，在属性中选择文字或图片。元素选择内容来源：固定内容、运行时提供；后续处理节点通过连线直接接收上游结果，无需添加中转元素。图片统一选择和排序，无需预先声明单张或多张。文字直接填写；需要引用其他文字时，在同一个编辑框的光标处通过「插入引用」选择来源，无需文字组合或模板节点。模型／生图的提示词使用相同编辑器。数字和开关等程序数据仍可由处理节点传递，旧定义保持兼容。
   循环内可选当前项、序号和带入的外部内容。字段路径、取第几项及拼接分隔文字均有普通表单；列表输入通过添加、移除逐项配置。
4. 文字元素可同时包含固定文字与引用。只有通过插入操作登记的引用会被解析；直接输入的普通 `{{...}}` 保持原文。模型输出中的 `{{...}}` 不会再次展开。
5. 保存并校验。校验显示按循环 maxItems 估算的调用上限；可以降低该值。保存允许未完成草稿，运行要求完整校验通过。
6. 点击运行，没有运行时内容时直接开始；需要提供内容时，表单只显示来源为「运行时提供」的元素；固定内容无需重复填写。文字直接填写或从资料库选择；图片通过素材选择器添加，显示缩略图，可上移和移除，无需填写 ID 或 JSON。运行开始前保存独立快照，派生运行保留未改动固定素材的原快照。服务端拒绝服务器文件路径。
7. 「首项试跑」先显示涉及的循环，再对每个循环的实际输入列表取首项；固定素材、运行时输入和上游生成的列表均适用。参考图片列表保持完整，其他节点正常执行。没有循环时禁用试跑。试跑限制保存在运行快照中，不修改草稿；试跑内的重新执行仍保持首项限制。zip 的两组输入须长度相等。

循环节点通过「打开循环子图」编辑内部节点，顶部「主流程」返回。将外部素材直接连到循环节点的「＋带入外部内容」端口即可创建入口，类型自动确定；子图按来源名称选择「循环外的内容」使用。「循环返回的结果」在子图未选中节点时配置，主流程不再配置没有消费方的输出映射。首版只支持一层循环。

连线可点击选中后按 Delete／Backspace 或点击工具栏「断开连线」删除；属性中的已连接输入也有独立断开按钮。拖动已连线的端点到空白处可断开，拖到兼容端口可改接。改接到不兼容端口或按 Escape 取消时保留原连线。断开只移除当前依赖，文字中的其他片段保留；等待上游的端口不会自动重新连接。断开和改接均可撤销。

返回列表时保存当前草稿，包括尚未完成的节点配置。调用节点只选择模型适配器，具体模型和调用方式在适配器设置中管理。支持框选、复制粘贴、撤销重做和展示分组。ID 不随显示名称改变。保存草稿后可以导出定义 JSON；导入只接受已注册节点，不自动执行。定义中不允许凭证，连接使用本机设置中的执行器。

画布卡片的默认标题只显示一次：文字、图片、模型调用或图片生成等；自定义名称时才补充节点类别。固定内容与输出类型不重复占行，运行时提供的素材保留对应提示。素材卡显示文字摘要或已选图片数量，处理节点保留连线入口。编辑器和运行快照使用同一套卡片。

## 节点配置

编辑旧草稿时将 input 显示为运行时提供的元素，保留节点和参数标识；保存后采用 element 契约。旧模板与已完整绑定的 concat 配置在编辑时转换为普通文字元素内的片段并保留分隔符，旧执行契约仍可读取；上游中转元素和预览节点只兼容旧定义，不再提供新建入口。编辑草稿移除没有消费方的主流程输出映射，循环返回映射保留。历史运行快照不改写。

检查、保存、列表收集、取列表项和配对操作的类型，以及循环的列表／外部内容类型，从绑定来源自动确定并随上游修改更新，不再重复手动声明；字段提取等确实无法静态确定的输出仍由用户声明。

内置示例只保留两个素材元素和一个循环；循环内部为理解图片、人工确认、生成图片，直接传递提示词和当前图片，不再添加转发模板、单图包装或预览节点。

所有节点的当前契约版本为 1，输出端口统一为 `value`。图结构为 `{schemaVersion:1,nodes,outputs}`。节点包含 `{id,type,version,name,config,inputs,position}`。

| 节点 | 配置与输入 |
| --- | --- |
| element | `valueType`、`source:"fixed"/"runtime"/"upstream"`；固定及运行时内容使用 `parameter`、`default`，上游来源仅兼容旧定义并使用 value 输入。文字可保存 `parts:[{kind:"text",text},{kind:"ref",ref:绑定}]`，运行时计算，引用自动成为图依赖；这类文字不作为运行输入参数。文字及图片可用 `{elementId}` 选择资料库素材，在运行准备阶段固定快照 |
| input（旧定义兼容） | `parameter`、`valueType`、`required`、`default`、`allowEmpty`；运行参数作为输出 |
| template（旧定义兼容） | `parts` 数组：`{kind:"text",text}` 或 `{kind:"ref",ref:绑定}` |
| model | `adapterId` 保存适配器 ID；`outputType` 选择适配器支持的输出格式；输入契约由适配器提供 |
| image.generate | `adapterId` 保存适配器 ID；`parameters` 为适配器声明的任务选项，`adapterConfig` 为适配器自有任务配置；输出图片列表 |
| transform | `operation` 为 field、concat、list、nth、zip、successes；`valueType` 声明输出类型 |
| foreach | `itemsType`、`maxItems`、`captureTypes`、`body:{nodes,outputs}`；输入 items 和捕获端口 |
| review | `valueType` 为 text 或 list&lt;image&gt;；输入 value |
| preview（旧定义兼容） | `valueType`；输入 value，不保存到内容库 |
| library.save | `valueType` 为 text、image 或 list&lt;image&gt;，`tags`、`source`；输入 value，输出元素 ID 列表 |

transform 的 field 使用 `path:["字段",0]`，输入 value 为 json；nth 使用从 0 起的 `index`；concat 使用 `keys:["a","b"]`、`separator`；list 使用 `keys` 声明逐个输入；zip 使用 `listType` 和可选 `otherListType`，输出 `list<json>` 的 `{a,b}` 列表；successes 只保留循环结果的成功项。json 与 text 不隐式互转。接收图片列表的端口可直接接收单图，执行时包装为单项列表，无需额外创建列表节点；执行契约仍兼容单图和列表，编辑旧草稿时将图片素材规范为列表，历史运行快照不变。收集图片时按输入顺序合并各组图片。循环汇总行的 outputs 保存 `{artifactRef,type,path}`，避免一次载入所有长文本；field 取到这种引用时读取对应产物，再检查声明的输出类型。

文字输入端口也可保存 `{kind:"text",parts:[...]}`，支持直接在模型提示词中组合固定文字和引用。引用只允许文字来源，并参与类型检查、循环检测和派生失效。删除引用连线同步移除该文字中的引用。同名来源通过独立标记区分。带引用的固定文字由执行器计算；运行时整段手动提供与计算引用互斥，移除引用后可切换。循环内可添加文字元素，引用当前文字项及带入的文字。

提示词直接连接上游时，属性面板显示来源及断开操作，不展示模板占位符；选择「补充文字」才进入组合编辑。主流程的参考图直接显示连接状态，无需先选「使用上游结果」，也不重复显示图片列表类型；循环内部仍保留当前项和外部内容的选择。

模型适配器边界：服务端注册入口为 `src/server/application/modelAdapters/index.js`，前端配置入口为 `src/renderer/src/features/modelAdapters/ModelAdapterFields.jsx`。工作流通过目录获取适配器的输入、输出、任务选项和配置界面，不导入具体后端实现。适配器负责输入契约、参数校验、执行配置快照、调用、资源标识、失败分类及安全取回；工作流仅负责连线、调度、产物持久化和检查。模型名称、CLI/API、服务地址和后端字段映射不由工作流解释。

`GET /api/workflow-node-types` 返回 `adapters` 目录，配置操作通过 `/api/workflows/adapters/:id/:operation` 转发，由适配器声明允许的 HTTP 方法，全部仅限本机。ComfyUI 的旧配置接口由适配器声明的兼容路由继续提供。`config.adapterInputs` 是适配器生成的输入契约提示，服务端在保存、运行以及读取历史执行节点时重新从适配器确定，不信任客户端伪造的类型。运行快照保存适配器生成的配置，修改软件设置不会改变原任务的安全取回配置。

兼容旧的 `config.comfyui` 和原适配器 ID，读取时由对应适配器转换，不改写历史运行记录。旧文字节点中的模型、effort 覆盖只在适配器兼容层读取，新界面不再提供这些控件；新节点使用 `adapterId` 并只接受目录中声明的任务参数，拒绝模型覆盖，默认使用适配器设置。旧 `executor` 字段仅作为适配器 ID 的兼容别名。适配器暂不可用时草稿仍可打开并重新选择，运行会明确报告不可用。新增适配器无需在工作流调度、服务、输入契约或运行界面中添加后端分支。

Grok 生图只开放 `parameters.aspectRatio`，不会忽略不支持的参数。文字调用使用独立上下文，在适配层拒绝所有工具。模型 JSON 输出始终经过 JSON 解析，可额外设置 `jsonSchema`；支持 type、properties、required、items、enum、additionalProperties、description，其他关键字报错。失败时保留原始回答。

ComfyUI 连接地址沿用设置。该适配器自有的 `config.adapterConfig` 可保存 API 图 `workflow`、提示词映射 `prompt:{nodeId,input}`、输出映射 `outputNodeId`、可选 `workflowName`。生图节点选择 ComfyUI 后，可直接读取已保存的工作流列表，或导入 API 图。选择工作流不会提交生成任务，也不会创建画布连线。只有一个候选的输出、提示词字段或图片入口会自动填写；多个候选时保留为空并要求选择。提示词来源可选沿用原工作流（不改任何文本字段），或用本节点内容替换显式选中的 `nodeId/input` 字段。只执行选定输出的依赖。参考图通过 `imageInputs:[{nodeId,input:"image"}]` 按列表顺序映射到不同的 LoadImage，最多 8 张；传图时数量须与映射一致，未传图时保留原工作流图片。重复入口、不可达入口和数量不符在提交前报错，未映射字段不变。旧定义未声明 imageInputs 时仍兼容唯一 LoadImage 的单图规则。服务未配置时校验会明确报错。首版不注册 ChatGPT 网页版或 Codex 原生生图。

## 检查、故障与继续

编辑草稿和查看运行分开，运行图与参数不会被草稿修改。运行面板可查看不可变图、输入来源、尝试记录、原始回答与观察到的工具参数。每个节点可通过「查看最近运行结果」查看上次执行的内容；这不会执行新调用，也不包含尚未运行的草稿修改。无需创建预览节点。循环子节点只在批次表中展示；完整实例分页放在折叠诊断区，主流程节点不受诊断分页影响。节点高级设置保留完整配置 JSON，正常操作无需填写具体模型或执行方式；ComfyUI 工作流和映射由适配器提供普通表单；节点结果优先显示名称及内容，内部标识与哈希留在来源和诊断信息中。

ComfyUI 配置中的「工作流参数」根据服务返回的节点定义生成数字、选项、开关或文本控件，可调整所选输出依赖中的尺寸、种子、步数、CFG、采样器、模型等实际存在的参数。提示词替换字段和 LoadImage 图片入口单独配置，已连接的字段不作为普通参数。数字离开输入框时生效，无效或超范围的数字恢复原值。修改直接保存到当前节点的 API 图副本，不改远端已保存的工作流；重新打开节点会重新读取控件定义并保留已保存参数和映射。

循环表每页 20 项，保持输入顺序和稳定项 ID。各项独立执行，失败不终止其他项。节点列表每页 100 个实例，事件按游标增量读取。人工检查可接受、修改文字后接受、选择图片子集后接受、拒绝，或明确选中多个检查后批量接受。原文与修改后的产物均保留。

暂停停止调度新的节点，已开始的节点可完成；取消尽力停止在途请求。取消后的迟到结果仅归档到原尝试，不会执行下游或保存内容库。

外部调用不自动重试。确认失败后可重试单个节点，复用成功上游；内容库保存失败只重试保存。结果未知时，不能按普通失败重试：可以核查远端后明确重新执行，或放弃。ComfyUI 已记录确认任务 ID 时可以「核查并取回」，此操作只查询原任务。Grok 暂不提供安全远端取回。

重启会恢复队列、检查等待和本地计算；已经记录提交意图的外部调用归为未知，不会自动再次提交。每次实际执行追加尝试记录，旧尝试不能覆盖当前输出。

修改配置后使用「用当前草稿派生运行」，也可以从成功节点发起「派生运行：重新执行此节点及下游」。默认复用严格快照匹配的成功结果，受影响的依赖闭包重新执行。展示名称与坐标不影响复用。首版派生以主图节点为失效单元：循环内部修改会使整个循环失效。循环汇总已被下游消费后，重试内部失败项须改用派生运行，保留已消费的历史结果。

## 存储与边界

- SQLite 迁移 40 新增工作流、版本、运行、实例、尝试、产物、引用、事件、保存回执和幂等命令；不改写已有聊天或资料内容。
- 全局外部请求上限为 2；Grok 与各 ComfyUI 服务资源上限为 1，聊天与工作流共用适配器资源锁。
- 每作用域最多 100 节点，总定义 300 节点，循环最多 1000 项，总展开上界 20000 实例。循环每次最多保持 8 个未完成输入项，文件按需读入。
- 所有工作流 API，包括定义、运行、事件、动作和媒体，均拒绝 LAN；请求定义／运行体最多 1 MiB。
- 图片固定在 `data/workflow-artifacts/`，尝试目录位于 `data/workflow-workspace/`。内容哈希与大小会在取回时核验。
- 归档不删除历史；首版不自动清理运行产物。已保存到内容库的图片有独立存储与保存回执。

升级前请停止应用并完整备份实际 data 目录。程序同时会在迁移前保存数据库快照到 data/backups，但这不替代资产备份。回退旧程序应恢复整套升级前数据。工作流两个目录也应纳入后续备份。
