# 首页搜索相关性

2026-09-09 权限更新：局域网共享现与本机拥有相同的应用权限，开放会话、会话关联及中间图片、编辑、回收站、整理配置和语义检索。仍无需登录，保留局域网地址及同源校验。下文原有 LAN 只读或私有内容隔离描述为历史设计，以本更新和 README 的局域网共享说明为准。

2026-09-09 补充：正常搜索结果总数为零且向量查询成功时，在独立的“可能相关”区域显示原始 topK 候选，明确提示可能不符合条件。普通结果及其计数保持不变；有正常结果时不展示此区域，翻到空页也不触发。候选继续遵守类型、标签和可见性筛选；回收站、局域网、关键词模式、空查询及服务失败不补候选。复用同一次向量查询，不额外调用模型。因此下表中的“女生”“宇宙飞船”等零命中查询现在可能出现独立候选组，并不代表确认命中。

2026-09-08：本机列表合并正文、文件名、已有图片描述的字面命中，以及通过相关性过滤的向量候选。字面命中优先，其内按向量排名排序；其余语义命中按相似度排序。合并去重后统一应用类型、标签、可见性和分页。描述字面命中不受 topK 限制，向量服务不可用时仍可使用。回收站、局域网和未请求语义搜索的接口维持原行为。

首页向量候选最低余弦相似度暂取 0.48。该值依据当前 qwen3-embedding:0.6b、1024 维、现有中文图片描述的实测选择，不是模型通用标准，也不是准确率。仅影响首页最终结果，Agent 和设置页的候选召回保持原有 topK 行为。
