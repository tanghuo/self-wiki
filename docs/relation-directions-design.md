# 关联方向（2026-09-08）

现有 related 两端按编号归一化，不能用 source_id 猜历史方向。本版保留主键与归一化、现有唯一键，增加 direction 和 reverse_name。数据库 direction 为 0 同名、1 source→target、-1 target→source、2 历史方向待确认；API 使用 symmetric/forward/reverse/unknown。名称为正向名称，反向名称独立保存，方向相对 API 返回的 sourceId/targetId。创建时方向相对请求端点，仓储归一化时翻转。标签关联亦支持方向，相对创建者与成员。

迁移仅添加列与重建读取视图，保留 ID、AI 绑定和拒绝记录；旧参考/改写/生成/包含等明确方向性名称标为 unknown，不猜测。不迁移正文和标签。唯一键继续限制同一对端点同名关系，方向不同的冲突明确报错，编辑现有关系解决。修改方向/反向名称也标记 AI 绑定已人工修改，撤销不得删除。

创建/编辑提供预设、正反名称、交换方向和完整语句预览；详情、标签卡片、画布统一解释方向。批量重命名只改正向名称，保留每条方向。标题关联沿用专有语义。兼容旧 API 未传方向的创建为 symmetric、旧 name-only 编辑保留方向。
